# Synapse AI - Hospital/Patient Management System

A comprehensive Next.js frontend with FastAPI backend for hospital/patient intake workflow, featuring AI-powered report analysis, multi-language support, and complete doctor portal.

## Features

### Core Features
- **Frontend**: Next.js 16 App Router, React 19, TypeScript with neo-brutalist design
- **Backend**: FastAPI with SQLite database
- **Multi-language Support**: 23 Indian languages with AI-powered translation
- **Speech & Audio**: OpenAI Whisper for speech-to-text, TTS for text-to-speech

### AI Integration
- **OpenAI GPT-4o-mini**: Follow-up questions, clinician summaries, report analysis
- **OpenAI GPT-4o Vision**: OCR for handwritten prescriptions, image report analysis
- **Dynamic AI Responses**: All medical content generated by AI (no hardcoded medical advice)

### Patient Features
- **Registration**: Multi-language patient intake with vitals and symptoms
- **Priority System**: AI-assisted triage priority calculation (low/medium/high)
- **Queue Management**: Real-time queue tracking with estimated wait times
- **Doctor Assignment**: Automatic specialty-based doctor assignment
- **Report Analyzer**:
  - Upload medical reports (PDF, images)
  - AI extracts key clinical findings
  - Color-coded parameter analysis (normal/slightly_abnormal/severely_abnormal)
  - AI-generated impact and suggestions in patient's language
- **Report Comparison**: Compare past and present reports with improvement tracking
- **Visit History**: Complete patient visit records and summaries
- **Prescriptions**: View and download prescriptions

### Doctor Portal
- **Doctor Authentication**: Simple ID-based login
- **Doctor Dashboard**: View assigned patients with queue status
- **Patient Review**: Comprehensive patient review interface
  - Patient profile and vitals
  - Reports with AI analysis
  - Visit history
  - Previous prescriptions
- **Prescription Builder**: Create prescriptions with medications
- **Handwritten OCR**: Upload handwritten prescriptions for AI extraction
- **Report Generation**: Generate patient reports in patient's language
- **Doctor Reassignment**: Change assigned doctor for patients
- **Print Support**: Print-friendly dashboards and reports

## Setup

### Prerequisites

- Python 3.14+
- Node.js 18+
- pnpm 12.3.4
- OpenAI API Key (required for AI features)

### Backend Setup

1. Navigate to the backend directory:
```bash
cd backend
```

2. Install Python dependencies:
```bash
py -m pip install -r requirements.txt
```

3. Configure environment variables in `.env` file:
   - `OPENAI_API_KEY`: Your OpenAI API key (required for AI features)
   - `MAX_QUESTIONS`: Maximum follow-up questions (default: 8)
   - `ESTIMATED_MINUTES_PER_PERSON`: Wait time calculation (default: 4)
   - `BASE_WAIT_TIME`: Base wait time in minutes (default: 8)

4. Start the backend server:
```bash
py main.py
```

The backend will run on `http://localhost:8000`

### Frontend Setup

1. Install dependencies:
```bash
pnpm install
```

2. Start the development server:
```bash
pnpm dev
```

The frontend will run on `http://localhost:3000`

### Access Points

- **Patient Intake**: `http://localhost:3000/en`
- **Doctor Login**: `http://localhost:3000/en/doctor-login`
- **Doctor Dashboard**: `http://localhost:3000/en/doctor-dashboard`

## API Endpoints

### Patients
- `POST /patients` - Create new patient
- `GET /patients/{patient_id}` - Get patient details with latest visit, assigned doctor, and prescriptions
- `POST /patients/{patient_id}/reports` - Upload medical report (PDF, JPG, PNG, WebP)
- `GET /patients/{patient_id}/reports` - List all patient reports with AI analysis
- `DELETE /patients/{patient_id}/reports/{report_id}` - Delete a report
- `GET /patients/{patient_id}/visits` - Get patient visit history
- `GET /patients/{patient_id}/prescriptions` - Get patient prescriptions
- `POST /patients/{patient_id}/reports/compare` - Compare two reports with AI analysis
- `GET /patients/{patient_id}/report-comparisons` - Get report comparison history

### Conversation
- `GET/POST /conversation/initial` - Get initial greeting in patient's language
- `POST /conversation/next` - Get AI follow-up question (OpenAI GPT-4o-mini)
- `POST /summary` - Generate clinician handoff summary (OpenAI GPT-4o-mini)

### Queue
- `GET /queue` - Get queue status (optional `?patient_id=` for individual info)
- `POST /queue` - Add patient to queue with automatic doctor assignment
- `PATCH /queue/{queue_id}/status` - Update queue status (waiting/in_consultation/completed)
- `PATCH /queue/{queue_id}/reassign` - Reassign doctor by queue ID
- `POST /queue/reassign-by-patient` - Reassign doctor by patient ID

### Doctors
- `GET /doctors` - List all active doctors
- `GET /doctors/{doctor_id}` - Get doctor details
- `POST /doctors/login` - Doctor login
- `GET /doctors/{doctor_id}/patients` - Get patients assigned to doctor
- `GET /doctors/{doctor_id}/patients/{patient_id}/review` - Get complete patient review data
- `POST /doctors/upload-handwritten` - Upload handwritten prescription for OCR
- `POST /doctors/{doctor_id}/patients/{patient_id}/generate-report` - Generate patient report

### Prescriptions
- `POST /prescriptions` - Create new prescription
- `GET /patients/{patient_id}/prescriptions` - Get patient prescriptions

### Audio
- `POST /audio/transcribe` - Transcribe audio using OpenAI Whisper
- `POST /audio/tts` - Convert text to speech using OpenAI TTS

### Health & Config
- `GET /health` - Health check
- `GET /config` - Get system configuration

## Database

The backend uses **in-memory SQLite** for development. Data resets when the server restarts.

For production persistence, change `DB_PATH = ':memory:'` to `DB_PATH = 'synapse.db'` in `backend/main.py`.

### Tables
- `patients` - Patient records (id, name, age, phone, sex, vitals, created_at)
- `reports` - Uploaded medical reports with AI analysis (id, patient_id, filename, content_type, bytes, extracted_text, key_points, created_at)
- `visits` - Visit history with AI summaries (id, patient_id, visit_date, summary, symptoms, risk, priority, created_at)
- `queue` - Queue entries with doctor assignment (id, patient_id, token, priority, status, assigned_doctor_id, consultation_type, created_at)
- `conversations` - Conversation history for AI memory (id, patient_id, role, text, created_at)
- `doctors` - Doctor records (id, name, specialty, phone, is_active, created_at)
- `prescriptions` - Prescription records (id, patient_id, visit_id, doctor_id, doctor_notes, medications, created_at, language)
- `report_comparisons` - Report comparison history (id, patient_id, past_report_id, present_report_id, comparison_summary, created_at)

## Priority Calculation

Priority is automatically calculated using AI assistance with rule-based fallback:
- **Vitals**: Blood pressure, blood sugar, temperature thresholds
- **Symptoms**: High-risk (breathlessness, chest pain) and moderate-risk symptoms
- **AI Analysis**: GPT-4o analyzes comprehensive data for accurate triage

Returns: `low`, `medium`, or `high`

## Doctor Assignment

When a patient joins the queue, the system automatically assigns an appropriate doctor based on:
- **Symptom Analysis**: Keyword matching to specialties
- **Specialty Mapping**:
  - Chest pain/breathlessness → Cardiology
  - Children → Pediatrics
  - Bone/joint issues → Orthopedics
  - Skin issues → Dermatology
  - Eye issues → Ophthalmology
  - Neurological symptoms → Neurology
  - Women's health → Gynecology
  - Default → General Medicine

## AI Features

### Report Analysis
- **AI-Powered Extraction**: GPT-4o Vision extracts key clinical findings from reports
- **Parameter Analysis**: Rule-based normality detection with AI-generated explanations
- **Color Coding**: Visual indicators (green/yellow/red) for parameter status
- **Multi-language**: Impact and suggestions in patient's language

### Language Support
- **23 Indian Languages**: Hindi, Bengali, Telugu, Marathi, Tamil, Gujarati, Kannada, Malayalam, Punjabi, Assamese, Odia, Urdu, Sanskrit, Nepali, Konkani, Maithili, Sindhi, Dogri, Kashmiri, Chhattisgarhi, Santali, Marwadi, and English
- **AI Translation**: Medical summaries translated with clinical accuracy
- **Speech Recognition**: Whisper API optimized for regional dialects
- **Text-to-Speech**: Natural voices for Indian languages

### AI Safety
- **No Hardcoded Medical Advice**: All medical content generated by AI
- **Fallback Messages**: Generic fallback when AI is unavailable
- **Clinical Accuracy**: All clinical summaries in English for doctors
- **Patient-Friendly**: Translated summaries for patients

## Development Notes

- This is a prototype, not production medical software
- Clinical decisions must remain with qualified healthcare professionals
- OpenAI GPT-4o-mini and GPT-4o Vision are used for AI features
- All AI features have fallback implementations if the API fails
- Database is in-memory (resets on restart) - change to file-based for persistence
